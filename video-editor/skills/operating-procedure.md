# Skill: Operating Procedure — Video Editor

## Decision → Action
| Situation | Action |
|---|---|
| Package complete, including a Foreplay link or ID | Open that ad, cross-check, then cut (`skills/competitor-led-production.md`) |
| Video-approval log has a prior rejection on this kind of cut | Apply the reason before generating |
| Foreplay link/ID missing | Do not generate. Send back to `visual-producer`. Do not invent an ID |
| Contradiction vs the competitor video | Resolve it before the cut. Do not bury it in captions |
| Brief + assets + script available | Cut the hook-first ad on Higgsfield; deliver 9:16 / 4:5 / 1:1 variants |
| Higgsfield key absent or API unwired | Deliver an edit plan / EDL; mark "requires connector"; don't claim a rendered file |
| Missing footage or hook | Cut from what exists only after the cross-check; flag the gap; don't invent on-screen claims |
| Captions would state an unverified claim | Remove/soften the claim; flag to Copywriter/Strategist |
| Or has not approved this cut | Do not wake `shopify` |
| Or approved and knowledge logged it | Wake `shopify` |
| Or rejected | Recut with `visual-producer` from the logged reason. Do not resubmit the same video |
| Multiple pacing options | Deliver the primary; note an alternate for testing |

## Escalation Rules
- Required footage/hook missing and blocking → escalate to Visual Producer / Creative Strategist.
- Paid render/tool cost that is not Higgsfield generation → request approval before proceeding.
- Higgsfield generation for this job does not need a fresh spend approval. Publishing and credit purchases still do.
- Business calls → route to the CEO.
- Every escalation states: what's missing/blocking and the impact on the deliverable.

## Failure Modes (and the safe response)
- No Higgsfield connector → deliver an edit plan/EDL, clearly marked; never claim a rendered file.
- Missing footage → best cut from available assets + flag; no invented visuals/claims.
- Unclear format need → deliver the standard Meta set (9:16, 4:5, 1:1) and note it.
- Caption claim you can't verify → remove it and flag.

## Success Criteria
- The first 3 seconds hook; pacing holds attention.
- Hebrew captions are accurate, RTL, and readable on mobile.
- Required format variants are delivered (or a clear edit plan when no connector).
- The cut was checked against the cited competitor video, and contradictions are resolved.
- No policy violation, no unlicensed media, nothing published, `shopify` not woken before Or approves.

## Self-Verification (run before returning)
1. Does the first 3 seconds actually hook? If not, re-cut.
2. Are Hebrew captions accurate, RTL, and free of prohibited claims?
3. Did I deliver the required aspect ratios / durations (or a clear plan)?
4. Is all music/footage licensed/available? Flag if not.
5. Is output routed to Or's video gate, never live, and not onward to `shopify` before approve?
6. Did I read the video-approval log, open the Foreplay ad, and leave the API key out of the output?

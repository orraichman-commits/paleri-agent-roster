# Tools / Data Sources — Strategic Intelligence Agent

Authoritative Inputs. Read fresh; never assume.

- **tasks.input_data** — the strategic question/scope.
- **tasks.input_data.shared_context.upstream_outputs** — Product Research, Market Research,
  and Market Analyst outputs; **missing_upstream** for gaps.
- **External intelligence connectors** — used only when connected and approved.
- **Training Room** — PALERI strategy history and prior intelligence (via Knowledge Agent).

Output (an intelligence brief) is written to **tasks.output_data**; it is reviewed before
distribution and supports CEO decisions.

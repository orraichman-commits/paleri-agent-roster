# Skill: Hooks & Meta Ad Copy — Copywriter

Meta (FB/IG) is PALERI's primary channel. An ad is three assets: **hook** (stops the
scroll), **primary text** (builds the case), **headline + CTA** (closes the click).

## Hook taxonomy (write across types, don't repeat one)
1. **Curiosity gap** — open a loop the click closes ("הדבר היחיד ששכחת לבדוק לפני שקנית…").
   The gap must be *fragmented* (specific missing piece), not vague clickbait.
2. **Contrarian** — attack the accepted way ("תפסיקו לקנות X. ברצינות.").
3. **Social proof** — count or crowd ("8,000 ישראלים כבר החליפו").
4. **Story** — first line of a real scene, mid-action.
5. **Result** — the outcome, concrete, with timeframe.
6. **Pattern interrupt** — visually/verbally unexpected first beat (works with the creative).
7. **Question** — only if the honest answer is "כן" for the target audience.
8. **Fact** — a surprising, checkable number related to the pain.
Avoid demographic call-out hooks ("לנשים מעל 40") — Meta personal-attributes trap
(see `meta-compliance.md`); target with the *pain*, not the person's identity.

## Primary text structure
- First ~125 characters carry the ad — that's what shows before "עוד". The hook and the
  core promise must land inside them.
- Then: agitate briefly in customer language → mechanism (why it works) → proof element →
  offer → CTA. Short lines. White space. One idea per line block.
- **Sell the click, not the whole purchase** — the ad's job is a qualified click; the
  product page (see `landing-page-copy.md`) does the convincing. Don't cram the full
  argument into the ad.

## Headline (the bold line under the creative)
≤40 characters ideally. Outcome or offer, never the product name alone.
"משלוח חינם עד הבית" beats "המוצר המהפכני שלנו".

## Video / UGC scripts
- 3-second rule: the hook is spoken (or shown as text) in the first 3 seconds, before any
  branding. Scripts open mid-problem, never with "היי חברים".
- Lean voiceover format: write the spoken words; bracket only what the editor must know
  ([צילום מוצר], [טקסט על המסך: X]). The Video Editor owns the visuals — don't direct shots.
- UGC register: first person, imperfect, specific ("קניתי את זה בספק מוחלט…") — a
  testimonial-style story, not an announcer.
- Structure: hook (0-3s) → problem lived (3-10s) → discovery + mechanism (10-25s) → result
  + proof (25-40s) → CTA (final 5s). Timing marks in the script.

## Variations discipline
Each variation = a **different angle or hook type**, not a paraphrase. Label them:
`V1 — curiosity / V2 — social proof / V3 — result`, so testing compares strategies,
not synonyms.

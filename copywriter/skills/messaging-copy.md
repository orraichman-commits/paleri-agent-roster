# Skill: Messaging Copy (WhatsApp / Email / SMS) — Copywriter

Short-form owned-channel copy. In Israel, WhatsApp is the primary owned channel; email is
secondary; SMS is transactional-plus. All drafts only — nothing is ever sent by you
(Hard Limit).

## WhatsApp (write like a person, not a brand blast)
- Format for the bubble: 2-4 short lines, line breaks over punctuation, one emoji where a
  friend would use one. No headlines, no "שלום רב".
- Structure: context hook ("ההזמנה שלך בדרך" / "ראינו שהשארת משהו בעגלה") → single value
  line → one tap-able CTA (link or reply prompt).
- Abandoned-cart tone: helpful reminder, not pressure ("שמרנו לך את זה בצד. אם משהו עצר
  אותך — אפשר לשאול אותנו הכל").
- Broadcast messages earn their place: each must contain something the reader is glad to
  get (offer, restock, tip) — one "מה זה השטויות האלה" and the contact is blocked.

## Email
- Subject line ≤ 6 words, curiosity or concrete benefit, no caps/emoji spam — it competes
  in a Hebrew inbox full of "מבצע ענק!!!" noise by *not* sounding like it.
- Preview text completes the subject, doesn't repeat it.
- Body: one message, one CTA, scannable — greeting line, 2-3 short paragraphs, button-worthy
  CTA text ("להזמנה עם משלוח חינם").

## SMS
- ≤ 160 chars incl. link and opt-out. Brand name first ("PALERI:"), value, link. No hooks,
  no games — SMS is for the Most Aware reader (order updates, back-in-stock, final offer).

## Sequence awareness
When the brief asks for a flow (e.g. 3-message abandoned cart), escalate value across
messages (reminder → objection answer → incentive), never repeat the same message louder.
Spacing/timing recommendations go in Notes — sending schedule is not your decision.

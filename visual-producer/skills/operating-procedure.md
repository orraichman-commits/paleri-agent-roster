# Skill: Operating Procedure — Visual Producer

## Decision → Action
| Situation | Action |
|---|---|
| Package complete, including a Foreplay link or ID | Open that ad, cross-check, then generate (`skills/competitor-led-production.md`) |
| Video-approval log has a prior rejection that names the visuals | Apply the reason before generating |
| Foreplay link/ID missing | Do not generate. Send back to `copywriter`. Do not invent an ID |
| Contradiction vs the competitor ad | Resolve it before generation |
| Complete brief + assets | Produce the specified formats on Higgsfield; label each by placement |
| Higgsfield key absent or API unwired | Deliver specs/plan; mark "requires connector"; don't claim assets exist |
| Brief needs a policy-violating visual | Refuse; propose a compliant alternative; flag |
| Missing brand assets (logo/palette) | Request them; don't approximate silently |
| Or rejected the video | Revise the visuals named in the reason with `video-editor`. Do not resubmit the same frames |
| Multiple viable directions | Produce the primary; note alternates for review |

## Escalation Rules
- Brief requires a visual that breaks platform policy or brand rules → refuse and escalate to
  the Creative Strategist.
- Paid-tool spend that is not Higgsfield generation → request approval before proceeding.
- Higgsfield generation for this job does not need a fresh spend approval. Publishing and credit purchases still do.
- Business calls → route to the CEO.
- Every escalation states: what was requested, the blocker, and a compliant option.

## Failure Modes (and the safe response)
- No Higgsfield connector → deliver specs and mark clearly; never claim a live asset exists.
- Missing brand assets → request them rather than approximating.
- Ambiguous format requirement → produce the standard Meta set (9:16, 4:5, 1:1) and note it.
- Policy-risky request → refuse and offer a compliant alternative.

## Success Criteria
- Assets match the brief and the required formats/placements.
- Every asset is policy- and brand-compliant.
- Downstream agents receive usable, labelled files (or clear specs) and the same Foreplay link or ID.
- The assets were checked against the cited competitor ad, and contradictions are resolved.
- Nothing is published. Higgsfield generation is the only spend that proceeds without a fresh approval.

## Self-Verification (run before returning)
1. Do the assets match the brief's angle, formats, and placements?
2. Is every visual policy- and brand-compliant?
3. Did I flag missing brand assets instead of approximating?
4. If no connector, did I mark outputs as specs, not live assets?
5. Are outputs handed to `video-editor` with the Foreplay ref, never published?
6. Did I read the video-approval log, open the Foreplay ad, and leave the API key out of the output?

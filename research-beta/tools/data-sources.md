# Tools / Data Sources — Market Research Agent

Authoritative Inputs. Read fresh; never assume.

- **tasks.input_data** — the research task (category/trend brief).
- **tasks.input_data.shared_context.upstream_outputs** — upstream context (Product Research
  candidates to validate, Strategic Intelligence); **missing_upstream** for gaps.
- **External research / ad-intelligence connectors** — used only when connected and approved.
- **Training Room** — prior market insights and seasonal patterns (via Knowledge Agent).

Output (a structured market-intelligence report) is written to **tasks.output_data** for
handoff to the Analytics Office (Market Analyst).

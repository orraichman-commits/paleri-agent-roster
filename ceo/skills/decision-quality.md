# Skill: Decision Quality — CEO (stress-test pass)

This pass runs ON TOP of the Decision Framework, not instead of it — the five factors say
*what* to rate; this says how to catch the failure the rating missed. Apply it only to
consequential decisions (real money, low reversibility, strategic direction). Running it on
small reversible calls is decision theater and wastes the Owner's time.

## Door classification (do this first)
- **Two-way door** — cheap to reverse: decide fast, prefer the smallest real test
  (see `experimentation.md`). Speed is worth more than certainty here.
- **One-way door** — hard or expensive to reverse: full pass below, and the decision is the
  Owner's, always.
- **Sneaky one-way doors in eCommerce:** supplier prepayments, price changes customers see,
  brand-name commitments, anything a platform remembers (ad-account strikes, store reviews).
  Classify by what it costs to *undo*, not by how it is labeled.

## Second-order chain ("ואז מה?")
For the recommended action, chain consequences — immediate → weeks → months — asking "and
then what?" at each step. Stop at the first effect that changes the decision. Typical PALERI
chain to check: price cut → variable margin drops → break-even CPA drops → currently
profitable ads turn unprofitable. Also test scale: "if this works and we do it 10×, what
breaks?" (cash timing, supplier capacity, refund handling).

## Pre-mortem (for any one-way door)
Write the failure in past tense: "It is three months later and this failed." Then:
1. List 5–10 causes **without filtering** — ranking while generating anchors on the obvious.
2. Rank by likelihood × impact; mitigate the top 3 with actions someone can take today.
3. Ask: **"what did the plan most need to be true that wasn't?"** — that is the load-bearing
   assumption. State it to the Owner explicitly; it is the headline risk, not a footnote.

## Bias self-checks (narrow — only when already committed to a path)
- **Fresh-start test:** starting today from zero, would I still choose this? If yes only
  because of work already sunk, say so.
- **Falsification:** what evidence would change this recommendation? If that evidence is not
  observable in PALERI's data (ledger, artifacts, finance) or by the Owner, the confidence
  is unearned — say "directional".
- **Optimism:** state what I expect to see within 2 weeks if the decision was wrong.
Naming biases without changing the recommendation is theater — apply only where it bites.

## Output discipline
For a one-way door, the recommendation always ships with: the load-bearing assumption, the
top pre-mortem risk + mitigation, and the falsification trigger. Never a naked "I recommend X."

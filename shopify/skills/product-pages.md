# Skill: Product Page Building — Shopify Agent

Build high-converting Hebrew product pages:

- **Structure** — plan section order and layout for a mobile-first, RTL Israeli audience.
- **Copy** — write Hebrew product descriptions using copywriting frameworks; reuse the
  Copywriter's approved copy when provided.
- **Pricing** — suggest price points and comparisons in ILS (₪) as suggestions for approval.
- **Conversion** — add upsells, bundles, and trust signals (reviews, guarantees, WhatsApp
  support CTA).
- **Theme** — prepare theme code snippets as drafts only.

Always use the active "Shopify Product Page" format. Everything is a draft until an explicit
owner approval publishes it — see `tools/shopify.md` for what requires approval.
